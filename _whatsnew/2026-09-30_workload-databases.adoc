=== Compatibilidad con varios sistemas de archivos por una sola instancia

Workload Factory for Databases admite varios sistemas de archivos por una sola instancia de Microsoft SQL Server. Puedes registrar varios sistemas de archivos en una instancia de SQL Server y solucionar al mismo tiempo un problema de configuración en varios sistemas de archivos de una instancia de SQL Server.
